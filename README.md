# Mishal Patel — Animated Portfolio

A responsive React portfolio with Framer Motion animations, custom CSS, Lucide icons and a dark futuristic aesthetic.

## Requirements
- Node.js 18+ (recommended)
- npm

## Run locally
1. Extract this folder.
2. Open a terminal inside the project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Build
Run `npm run build`. The production output is in `dist/`.

## Deploy to Vercel
1. Push this project to GitHub.
2. In Vercel, import the repository.
3. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

## Customize
- Project cards and links: `src/main.jsx` (the `projects` array).
- Social/contact links: contact section in `src/main.jsx`.
- Design and responsive layout: `src/style.css`.
- SEO title/description: `index.html`.

Note: some project entries are concept showcases and use placeholder links (`#`). Replace them with your real project URLs when ready.
